# Local simulation input data

Large reference meshes and derivatives belong here for local use and are ignored by git. Fetch the four-chamber MRI mesh with `scripts/fetch_reference_mesh.py`.

The currently evaluated model is from the [Four-Chamber Human Heart Model](https://zenodo.org/records/10526554), licensed CC BY-NC 4.0. Keep its source and derivatives local unless your use complies with that license. See the simulation README for attribution and limitations.
